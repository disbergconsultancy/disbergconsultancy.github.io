# Hero models

- `ninja.glb`: the Runner. Made by the project owner with Tripo (generated, auto-rigged with
  Mixamo bone names, refined: blades removed), with six Mixamo-style clips: Running, Jump,
  Running Slide, Stumble, Falling Back Death, Victory (all in place). About 5.8k triangles.
  config.gd maps the game's moves to the clips ("clips"); moves without a clip use the
  block figure's poses (scripts/model_character.gd).
  Licence: check Tripo's (and the clips' source) terms before release.
