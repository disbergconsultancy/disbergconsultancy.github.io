# Hero models

- `ninja.glb`: the Runner. Made by the project owner with Tripo (generated, auto-rigged with
  Mixamo bone names), cleaned up with tools/models: the hand blades, the hip scabbard and the
  floor shards removed, the back katana kept; then the leftover blade steel (cut_steel.mjs) and
  the triangles that stretched between a hand and a leg (cut_webs.mjs). About 6.6k triangles.
  Licence: check Tripo's terms for the plan it was made on before release.
