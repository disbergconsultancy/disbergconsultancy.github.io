# Hero models

- `ninja.glb`: the Runner. Made by the project owner with Tripo (generated, auto-rigged with
  Mixamo bone names) and refined by them (blades removed). About 5.8k triangles, 512 px textures.
  No animation clips yet: it takes the block figure's poses (scripts/model_character.gd).
